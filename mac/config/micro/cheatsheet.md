# micro: lo que más se usa   (cerrar esta pestaña: Ctrl-q)

Alt = Option derecho.  Ctrl-g abre esta hoja desde cualquier archivo.

## Archivo
    Ctrl-s   guardar               Ctrl-q   cerrar (sale si es el último)
    Ctrl-o   abrir archivo         Ctrl-t   nueva pestaña
    Alt-,    pestaña anterior      Alt-.    pestaña siguiente

## Editar
    Ctrl-z   deshacer              Ctrl-y   rehacer
    Ctrl-c   copiar                Ctrl-x   cortar          Ctrl-v   pegar
    Ctrl-a   seleccionar todo      Ctrl-k   cortar la línea
    Ctrl-d   duplicar la línea     Alt-↑/↓  mover la línea
    Tab / Shift-Tab   indentar / quitar indentación
    Shift-flechas     seleccionar   (mouse: doble clic palabra, triple línea)

## Buscar e ir
    Ctrl-f   buscar (Enter)        Ctrl-n   siguiente       Ctrl-p   anterior
    Ctrl-l   ir a la línea         Ctrl-Home / Ctrl-End   inicio / fin del archivo
    Alt-{ / Alt-}   párrafo anterior / siguiente

## Varios cursores
    Alt-n    siguiente igual a la selección      Alt-p   quitar el último
    Alt-c    cancelar todos

## Otros
    Ctrl-e   línea de comandos: help, set, vsplit, hsplit, replace ...
    Ctrl-w   cambiar entre divisiones          Ctrl-r   números de línea
    Ctrl-b   ejecutar un comando de shell      Alt-g    ver atajos en la barra de abajo
